# Data

## Layout

| File | Rows | Key | Content |
|---|---|---|---|
| `raw/papers.csv` | 209 | (`paper_id`, `author`) | Studies from the reference meta-research table: metadata, published (human) CLAIM domain scores, reference, link |
| `raw/llm_evaluations.csv` | 180 | (`paper_id`, `evaluator`) | CLAIM item ratings `q1`–`q42` from ChatGPT, Gemini and Claude for 60 papers |
| `processed/` | — | — | Generated by `python -m src.data`; not versioned |

Join: `llm_evaluations.paper_id → papers.paper_id` (many-to-one). The combined
long table (Humans + 3 LLMs per paper) is built by `src.data.build_full_dataset`.

Each fact is stored once. Paper-level columns live only in `papers.csv`; domain
scores for LLMs are **not stored** — they are computed from the item ratings.

## Provenance

Exported from `Metaresearch_dataset.xlsx` (sheets `Original_Database`,
`Full_Dataset`). The prompt used for the LLM assessments is in
`reports/paper/sections/6Appendix.tex`. Only the structure was changed: column names to
snake_case, leading/trailing whitespace removed, dates to ISO 8601, two-row
header flattened. Values are untouched; value cleaning happens in `src/data.py`.

Not exported (derivable):

- `Full_Dataset` paper columns and *Humans* rows → `papers.csv`
- `Full_Dataset` domain scores (Excel formulas) → `compute_domain_scores`
- `Reduced_Dataset` (copy of `Full_Dataset` without items) → `build_reduced_dataset`

## Data dictionary

### `papers.csv`

| Column | Description |
|---|---|
| `paper_id` | Reference number in the source study (not unique: see notes) |
| `author`, `year`, `journal`, `country` | Bibliographic data |
| `images`, `segmentation`, `cases`, `dataset`, `validation`, `performance_evaluation`, `public_code` | Study characteristics. `cases = NR` → not reported |
| `study_description_domain` … `performance_domain` | Published CLAIM domain scores (0–1) |
| `all_domains` | Published overall CLAIM score (0–1) |
| `paper`, `link`, `link_type` | Full reference and link (DOI or Google Scholar search) |
| `note` | Curation note |

### `llm_evaluations.csv`

| Column | Description |
|---|---|
| `paper_id` | → `papers.paper_id` |
| `evaluator` | `ChatGPT`, `Gemini`, `Claude` |
| `evaluation_date` | Date of the assessment (YYYY-MM-DD) |
| `q1` … `q42` | CLAIM 2020 item rating: `Yes`, `No`, `Notapplicable` (normalized in code to `Not applicable`) |
| `annotation` | Curation note |

### CLAIM domains (`src.data.DOMAINS`)

| Domain | Items |
|---|---|
| Study description | 1–6, 40–42 |
| Dataset description | 7–21, 33–34 |
| Model description | 22–27 |
| Performance | 28–32, 35–39 |

Score = #Yes / (#Yes + #No); `Not applicable` and missing ratings are excluded.

## Known issues
